# 放置天地 · 單機版

以 [afei.gg](https://afei.gg/) 的放置型 MMORPG 為參考，重新實作的**純前端單機版本**。
無需註冊、無需伺服器，進度存在瀏覽器 `localStorage`。

## 與原站的差異

| 系統 | 原站 | 本專案 |
|---|---|---|
| 帳號／連線 | 伺服器帳號、即時多人 | 單機，存檔在瀏覽器 |
| 交易所 | 玩家競標／一口價 | **隨機交易所**：每 3 分鐘自動換貨，可用金幣／藍鑽購買各種道具 |
| 世界王 | 全服共同討伐 | 單人限時挑戰，依傷害給獎 |
| 血盟／隊伍／聊天 | 有 | 無（單機無意義） |
| 美術／音效 | 官方素材 | 原創 CSS + Emoji + WebAudio 合成音 |

## 已實作系統

- **角色**：4 職業（騎士／妖精／法師／黑暗妖精）、性別、初始屬性配點
- **戰鬥**：自動掛機、普攻／技能、爆擊、暈眩、怪物重生、死亡懲罰
- **成長**：等級 1–60、經驗曲線、每級屬性點、職業主屬性自動成長
- **狩獵場**：7 張地圖、12 種怪物、等級門檻、掉落表
- **裝備**：9 個部位、5 種稀有度、強化（安定值／降級）、祝福強化
- **背包**：分類、裝備比較、使用、出售、批次堆疊
- **隨機交易所**：8 格隨機商品（補給／裝備／材料／鑽石珍品），自動刷新＋手動刷新
- **製作**：7 種配方（防具、武器、卷軸、藥水、龍系裝備）
- **抽獎**：潘朵拉黑市，單抽／十連，四階稀有度機率
- **兌換**：藍鑽／金幣兌換固定商品
- **世界王**：60 秒限時、傷害排名、冷卻
- **轉世**：等級 20 後重生，每次永久 +5% 全能力
- **離線收益**：最多累積 12 小時（效率 75%）
- **其他**：5 種面板配色、音效開關、自動喝水、存檔匯出／匯入

## 執行方式

直接雙擊 `index.html` 即可（純靜態、無建置步驟）。

若瀏覽器對 `file://` 的 `localStorage` 有限制，改用本機伺服器：

```bash
python -m http.server 8000
# 開啟 http://localhost:8000
```

## 目錄結構

```
index.html          畫面骨架
css/style.css       樣式（含 5 種主題變數）
js/data.js          職業、道具、怪物、地圖、配方等資料表
js/engine.js        存檔、數值計算、戰鬥迴圈、商店、抽獎、離線結算
js/ui.js            畫面渲染、面板、Modal、音效
js/main.js          啟動
```

## 存檔

- 自動儲存於 `localStorage`（key：`afei_single_v1`），每 8 秒與關閉頁面時寫入
- 設定頁可**匯出／匯入** JSON 存檔，或刪除存檔重新開始
